### Building with AI

These days, I work with AI in two ways: using coding agents to build software,
and building services that use AI agents to get things done.

Claude Code and Codex are also part of my regular development workflow.
I use them to explore codebases, discuss approaches, plan changes, implement
them, and investigate test failures.

For larger changes, I work through a plan with the agent before it starts
changing code. Markdown instructions and Git worktrees help keep the work
focused and easy to review.
